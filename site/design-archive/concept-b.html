The product problem

Agents keep losing the evidence.

Every AI agent framework today has the same problem: sessions start from scratch, context is lost, and agents never learn from past interactions.

01

You explain your architecture to your coding assistant on Monday. On Tuesday it has no idea what you said.

02

A support bot asks the same onboarding questions every time a returning customer reaches out.

03

Your team runs five AI tools on one project. None of them share what they learned.

Running example

The MySQL to PostgreSQL switch, end to end.

One conversation becomes typed memories. A contradiction becomes an explicit edge. The query returns the current fact with the relationships attached.

03

Contradictions become edges.

The new database fact conflicts with the old one, so the old fact is superseded.

graph mutationCypher flavored
MATCH (old:Memory {id: "fact:database:mysql"})
MATCH (new:Memory {id: "fact:database:postgresql"})
MATCH (why:Memory {id: "reason:graph-support"})
CREATE (new)-[:SUPERSEDES {detected_by: "contradiction"}]->(old)
CREATE (new)-[:BECAUSE]->(why)
-current database = MySQL
+current database = PostgreSQL
↳(PostgreSQL)-[:SUPERSEDES]->(MySQL)

What it does

A memory engine, not a pile of chunks.

Feed it any conversation. It extracts what matters, stores typed nodes, and returns the few memories that answer the question with the relationships that explain them.

Remember everything

Feed it any conversation. It extracts the facts, preferences, and events automatically and stores them as typed nodes.

Comparison

Where flat memory loses the thread.

Vector similarity is still useful. Kora keeps it in the same query path as graph traversal, so the result can be similar and related.

Dimension Traditional Kora
Memory structure Flat text chunks Connected knowledge graph
Retrieval Find similar text Follow relationships, not just similarity
Updates Old info mixed with new Contradictions detected, stale facts superseded
Learning Starts fresh each session Consolidates over time, forgets noise
Sharing Locked to one tool Any agent can plug in, framework-agnostic
Privacy Your data on their servers Self-hosted, data never leaves your infra

Architecture

Graph and vector live in one database.

Apache AGE and pgvector run inside the same PostgreSQL instance. Graph traversal and vector search share one database, one query path, and no sync between two stores.

Get started

Self-host the memory graph.

Run locally with Docker Compose or install into Kubernetes with Helm. Python SDK and Go CLI are also available.

Docker Composecopy
# Docker Compose
cat > .env <<EOF
POSTGRES_PASSWORD=$(openssl rand -hex 16)
KORA_API_KEYS=$(go run ./cmd/cli keys generate)
EOF
docker compose up
HelmKubernetes
# Helm
helm install kora ./charts/kora -n kora --create-namespace \
  --set postgres.existingSecret=my-postgres-secret \
  --set auth.existingSecret=my-api-keys
